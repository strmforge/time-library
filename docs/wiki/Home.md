**Time Library / 时间图书馆**: one memory for all your AI agents, on your own
server, every memory backed by the original words.

2026.11.23 is a **rebuild**: one server on your NAS and a small client on each
computer, instead of a full set of services on every computer.

- [Why A Rebuild](Why-A-Rebuild.md): what changed from 2026.9.11 and why.
- [Getting Started](Getting-Started.md): the server on a NAS, then one sentence per agent.
- [Connecting An Agent](Connecting-An-Agent.md): how an agent describes itself, checks it, and reports it.
- [Moving From An Earlier Version](Moving-From-An-Earlier-Version.md): from 2026.9.11 and before.
- [FAQ](FAQ.md)
- [Release History](Release-History.md)

The [README](../../README.md) covers how it works and what is (and is not) in this version.
