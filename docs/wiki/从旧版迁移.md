# 从旧版迁移

2026.9.11 及更早的版本在每台电脑上都跑一整套服务，还各自留着一份 agent 会话。2026.11.23 是
一次重构（[为什么](为什么重构.md)）；旧版自己的"一键更新"装不上它，免得不小心覆盖掉旧安装。
2026.7.11 起的旧版可能会提示有新版本，但更新什么都不会装。

先装好[服务端](快速开始.md)，然后一台一台迁：

1. 把「设备」页的那句话发给这台电脑上的 agent。它会装好客户端、接进来。
2. `tl.py old-install scan` 列出旧版的安装目录、旧服务和旧版留下的历史，每一份都附好导入命令。
   每个 agent 导入属于自己的那几份。导入的历史在服务端先扣着，等你在「导入」页点开始才整理
   （开始前会先告诉你预计用多少 token）。
3. `tl.py old-install stop` 停掉旧服务。
4. 每个 agent 删掉自己配置里指向旧目录的项（MCP、提问前钩子、旧版 skill）。
5. `tl.py old-install archive --to <文件夹>` 把每个旧目录打成 tar 留一份，并读回来核对。
6. `tl.py old-install remove` 停掉并删除旧服务和旧目录。没有核对过的备份时它会拒绝。

要回退，旧版本一直留在[版本发布页](https://github.com/strmforge/time-library/releases)。
