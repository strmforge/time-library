# 常见问题

**它是另一个聊天工具吗？**
不是。你继续在原来的 agent 里工作；时间图书馆在旁边收集、提炼，需要时把记忆递回去。

**一定要 NAS 吗？**
x86-64（Intel / AMD）芯片、能跑 Docker、一直开着的机器都行；还没有 ARM 版镜像。服务端为家里局域网设计：HTTP 加每台电脑一个令牌。
不要原样暴露到公网。

**哪些 agent 能接？**
能执行命令、能把自己的会话文件描述清楚的都能接（JSON lines、zstd 压缩的 JSON lines、
每个会话一个 JSON 文件、SQLite）。不用等谁写适配，见[接入 agent](接入agent.md)。

**什么会离开我的电脑？**
只有对话。工具调用、工具输出、思考过程、注入的上下文在本机就去掉。密钥一律打码；
邮箱、手机号、证件号默认打码。

**什么会发给模型？**
正在提炼、整理、作答的那段对话或那几条记忆，发到你为该任务选的地址。中转是第三方；
自带的本机模型全程不出 NAS。

**NAS 关了，或者换了地址呢？**
客户端记着读到哪，回来接着传；各 agent 自己的会话文件就是缓冲。NAS 换了地址，客户端会在
家里局域网里找回它配对过的那台服务端。

**模型余额用完了呢？**
任务换到备用模型或者先停下，过一阵自己再试；同一段不会提炼两次。

**忘了管理密码。**
在登录页点「忘记密码?」，填服务端钥匙：服务端 `data/` 文件夹里 `admin_token.txt` 的那一行。

**怎么升级？**
服务端：`docker compose pull && docker compose up -d`。客户端会自己跟着服务端升级。

**旧版的功能去哪了？**
见[为什么重构](为什么重构.md)。旧版留下的历史可以带过来：[从旧版迁移](从旧版迁移.md)。
